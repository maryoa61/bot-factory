# 🤖 کارخونه‌ی ربات‌ساز تلگرام (Bot Factory)

یک ربات تلگرام که بر اساس **درخواست کاربر**، ربات سفارشی برای او می‌سازد و تحویل می‌دهد.

## چطور کار می‌کند؟

1. کاربر به ربات اصلی می‌گوید چه رباتی می‌خواهد (متن آزاد)
2. سیستم درخواست را می‌فهمد و با یکی از **۱۰ قالب پشتیبانی‌شده** جور می‌کند
3. توکن بات (از @BotFather) و یوزرآیدی ادمین را می‌گیرد
4. رباتِ همان درخواست را ساخته و **همراه پنل مدیریت** به کاربر تحویل می‌دهد

## ۱۰ ربات پشتیبانی‌شده

| # | ربات | امکانات |
|---|------|---------|
| 1 | پاسخگوی خودکار | کلمه کلیدی → جواب، پاسخ پیش‌فرض |
| 2 | فروشگاه / درگاه | محصولات + خرید با ⭐ ستاره‌ی تلگرام |
| 3 | جوینر / ممبرگیر | گیت عضویت اجباری |
| 4 | مدیریت گروه | کیک، بن، میوت، ضدلینک، خوش‌آمد |
| 5 | اطلاع‌رسانی / برادکست | ارسال همگانی به کاربران |
| 6 | خوش‌آمدگویی | پیام خوش‌آمد به اعضای جدید |
| 7 | نظرسنجی | ساخت نظرسنجی با یک دستور |
| 8 | ضداسپم | حذف لینک و کلمات فحش |
| 9 | کارت ویزیت / معرفی | نمایش معرفی‌نامه به بازدیدکننده |
| 10 | فوروارد خودکار | انتقال پیام بین کانال‌ها |

## ساختار

```
src/
├── main.py          # نقطه ورود: ربات اصلی + اجرای هم‌زمان همه‌ی ربات‌ها
├── factory.py       # ربات اصلی: تشخیص درخواست + دریافت توکن + تحویل ربات
├── templates.py     # موتور قالب‌ها: ۱۰ نوع ربات + تطبیق کلیدواژه
├── tenant_bot.py    # هسته‌ی ربات سفارشی: پنل مدیریت + گیت عضویت
├── tenants.py       # اجرا/توقف هر ربات (polling هم‌زمان)
├── db.py            # SQLite (aiosqlite): tenant ها + کانفیگ JSON
└── features/        # کتابخانه‌ی امکانات
    ├── autoreply.py
    ├── shop.py
    ├── joiner.py
    ├── groupadmin.py
    ├── broadcast.py
    ├── poll.py
    └── forward.py
```

## دیپلوی روی Railway

1. این ریپو را به گیت‌هاب پوش کن (انجام شده)
2. در [Railway](https://railway.app) → New Project → Deploy from GitHub repo → این ریپو
3. در تب Variables:
   - `MAIN_BOT_TOKEN` → توکن ربات اصلی (ساخته‌شده با @BotFather)
   - (اختیاری) `MAX_BOTS_PER_USER` → حداکثر ربات برای هر کاربر (پیش‌فرض ۵)
4. Deploy بزن — آماده است!

> نکته: دیتابیس روی دیسک کانتینر می‌ماند. برای ماندگاری بعد از restart، یک Volume در Railway بساز و `DATABASE_PATH` را به مسیر داخل آن بده.

## ساخت ربات اصلی

با @BotFather: `/newbot` → نام → توکن را در `MAIN_BOT_TOKEN` بگذار.
