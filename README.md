# 🤖 کارخونه‌ی ربات‌ساز تلگرام (Bot Factory) — Cloudflare Worker

یک ربات تلگرام که بر اساس **درخواست کاربر**، ربات سفارشی برای او می‌سازد و تحویل می‌دهد — با پنل مدیریت.

## چطور کار می‌کند؟

1. کاربر به ربات اصلی می‌گوید چه رباتی می‌خواهد (متن آزاد، فارسی یا انگلیسی)
2. سیستم درخواست را با **موتور تشخیص کلیدواژه** (نرمال‌سازی فارسی: ي→ی، ك→ک، آ→ا، حذف نیم‌فاصله و اعراب) با یکی از **۱۰ قالب** جور می‌کند
3. توکن بات (از @BotFather) و یوزرآیدی ادمین را می‌گیرد (با `getMe` تأیید می‌شود)
4. رباتِ همان درخواست را ساخته، **وب‌هوکش را خودکار روی همین Worker تنظیم می‌کند** و همراه پنل مدیریت تحویل می‌دهد

## ۱۰ ربات پشتیبانی‌شده

| # | ربات | امکانات |
|---|------|---------|
| 1 | پاسخگوی خودکار | کلمه کلیدی → جواب (`/addreply کلید|جواب`) |
| 2 | فروشگاه / درگاه | محصولات + خرید با ⭐ ستاره‌ی تلگرام (`/addproduct نام|قیمت`) |
| 3 | جوینر / ممبرگیر | گیت عضویت اجباری (`/setchannel @کانال`) |
| 4 | مدیریت گروه | کیک، بن، میوت، ضدلینک، خوش‌آمد (`/kick /ban /mute /antilink /setwelcome`) |
| 5 | اطلاع‌رسانی / برادکست | ارسال همگانی به کاربران (`/broadcast متن`) |
| 6 | خوش‌آمدگویی | پیام خوش‌آمد به اعضای جدید |
| 7 | نظرسنجی | ساخت نظرسنجی با یک دستور (`/poll سوال|گزینه۱|گزینه۲`) |
| 8 | ضداسپم | حذف لینک و کلمات فحش |
| 9 | کارت ویزیت / معرفی | نمایش معرفی‌نامه (`/setinfo متن`) |
| 10 | فوروارد خودکار | انتقال پیام بین کانال‌ها (`/setforward @مبدا|@مقصد`) |

## معماری

```
src/
├── index.ts          # ورودی Worker: /webhook (ربات اصلی) + /wh/<token> (ربات‌های ساخته‌شده)
├── factory.ts        # ربات اصلی: فلو ۳ قدمی (درخواست → توکن → یوزرآیدی → تحویل)
├── templates.ts      # موتور قالب‌ها: ۱۰ نوع ربات + تطبیق کلیدواژه (نرمال‌سازی فارسی)
├── tenant.ts         # مونتاژ ربات سفارشی بر اساس قالب
├── panel.ts          # پنل مدیریت: config به‌صورت JSON داخل متن پیام آینه می‌شود
├── registry.ts       # D1: tenants + pending (فلو ساخت) + users (برای برادکست)
├── env.ts            # تایپ‌های bindings
└── features/         # کتابخانه‌ی امکانات (فقط فیچرهای فعالِ هر قالب لود می‌شوند)
    ├── autoreply.ts  ├── shop.ts     ├── joiner.ts   ├── groupadmin.ts
    ├── broadcast.ts  ├── poll.ts     ├── card.ts     └── forward.ts
```

**استیت کجاست؟**
- Worker کاملاً **Stateless** است — هیچ state ای در حافظه‌ی پروسس نگه نمی‌دارد.
- **D1 (یک دیتابیس کوچک)** → فقط رجیستری: ردیف هر ربات (توکن، قالب، مالک، کانفیگ JSON) + فلو نیمه‌کاره‌ی ساخت + لیست کاربران برای برادکست.
- **خود تلگرام** → پنل مدیریت هر ربات، کانفیگ را به‌صورت JSON داخل متن پیام نشان می‌دهد و بعد از هر تغییر، همان پیام ادیت می‌شود (شیشه‌ای و همیشه تازه).
- هر ربات ساخته‌شده یک پات می‌گیرد: `POST /wh/<token>` با سکرت اختصاصی خودش.

## دیپلوی روی Cloudflare Workers

پیش‌نیاز: اکانت [Cloudflare](https://dash.cloudflare.com) + [Node.js](https://nodejs.org) روی سیستم.

```bash
# 1) نصب و لاگین
npm install
npx wrangler login

# 2) ساخت دیتابیس D1
npx wrangler d1 create bot-factory
#    → آیدی خروجی را در wrangler.toml جایگزین REPLACE_WITH_YOUR_D1_ID کن

# 3) جدول‌ها (در اولین درخواست هم خودکار ساخته می‌شوند، ولی بهتر است همین‌جا):
npx wrangler d1 execute bot-factory --remote --file ./schema.sql

# 4) سکرت‌ها (توکن ربات اصلی از @BotFather + یک رشته‌ی تصادفی):
npx wrangler secret put MAIN_BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET

# 5) دیپلوی
npx wrangler deploy
#    → آدرس Worker مثل: https://bot-factory-worker.<your-subdomain>.workers.dev

# 6) وصل کردن تلگرام (ربات اصلی):
curl "https://api.telegram.org/bot<MAIN_BOT_TOKEN>/setWebhook?url=https://bot-factory-worker.<your-subdomain>.workers.dev/webhook&secret_token=<WEBHOOK_SECRET>"
```

> ربات‌هایی که فکتوری می‌سازد، وب‌هوکشان **خودکار** روی `https://<worker>/wh/<token>` تنظیم می‌شود — نیازی به کار دستی نیست.

**تست:**
- `npm run typecheck` → بررسی تایپ‌ها
- `npm run selftest` → تست موتور تشخیص (۱۳ جمله‌ی نمونه)
- `npm run dev` → اجرای محلی wrangler
